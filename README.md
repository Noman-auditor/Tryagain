# Nora Tunnel

A secure, high-performance, modern Android VPN client supporting multi-protocol routing, DNS management, and local network diagnostics.

## Features
- **Multi-Protocol Support:** WireGuard, VLESS, VMess, Trojan, ShadowSocks, OpenVPN.
- **Routing Studio:** Custom domain, IP CIDR, and per-app routing rules.
- **Nora Lab & Diagnostics:** Real TCP, ping, and DNS testing utilities.
- **Privacy First:** Fully local-first storage and sensitive log redaction.

## Building from Source
```bash
./gradlew assembleDebug
```
